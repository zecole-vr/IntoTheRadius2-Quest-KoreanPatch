# Into the Radius 2 — Quest 한글패치

Meta Quest 단독판 **1.2.2 / 473002**용 비공식 한글패치입니다.
PCVR판용 패치를 Quest 환경에 맞춰 이식했으며, Windows에서 설치합니다.

> 현재 **RC2 공개 전 검토본**입니다. 원 번역 제작자의 이식·재배포 허락 확인과
> 새 간편 설치 도구의 실기 설치·복구 검증이 남아 있습니다.

## 다운로드

배포가 공개되면 이 저장소의 **Releases**에서
`ITR2_Quest_Korean_1.2.2_RC2_EASY_REVIEW.zip`을 받으세요.
GitHub의 **Code → Download ZIP**은 도구 소스이며 설치용 배포본이 아닙니다.
현재 릴리스 초안이 공개되지 않은 경우 다운로드는 제공되지 않습니다.

## 설치

1. 배포 ZIP 전체를 PC의 쓰기 가능한 폴더에 압축 해제합니다.
2. 게임을 종료하고 Quest를 USB로 연결한 뒤 헤드셋에서 USB 디버깅을 허용합니다.
3. **설치.bat**을 더블클릭하고 완료될 때까지 기다립니다.
4. 게임을 실행합니다. 한국어를 따로 선택할 필요가 없습니다.

Python 별도 설치는 필요 없습니다. ADB가 없으면 처음 한 번 Google 약관 확인 후
공식 파일을 자동 다운로드합니다. 기존 ADB가 있으면 자동으로 사용합니다.
자세한 내용은 [설치방법](설치방법.txt)을 읽어 주세요.

## 지원 환경

- Windows 10/11 x64, 개발자 모드 및 USB 디버깅을 허용한 Quest.
- 정식 설치된 Quest 단독판 1.2.2 / versionCode 473002 전용.
- PC 최소 12GiB, Quest 최소 약 5GB 여유 공간.
- Quest 3에서 게임 패치 플레이 확인. 다른 기기 및 게임 업데이트 버전은 미검증.

## 복구 및 백업

게임을 종료하고 연결한 뒤 **복구.bat**을 실행하면 영문 원본으로 복구합니다.
세이브 진행은 되돌리지 않습니다. `userdata`의 원본·세이브 백업은 보관하세요.
개인 백업이 들어 있는 설치 폴더 전체를 재압축해 공유하지 마세요.

## 검증 범위

EXE로 생성한 게임 파일은 실제 플레이 확인본과 SHA-256이 일치합니다.
모의시험 13개 및 한글·공백 경로 실행을 확인했습니다.
새 EXE를 통한 실제 기기 설치·복구 시험은 아직 하지 않았습니다.
일부 영어와 번역 누락이 남을 수 있습니다. [검증 기록](VALIDATION.md)을 참고하세요.
