# Into the Radius 2 Quest 한글패치

Meta Quest 단독판 **1.2.3 (478362)**용 비공식 한글패치입니다.

## 번역 출처 및 제작

[refracta/itr2-ko PCVR 한글패치](https://github.com/refracta/itr2-ko) 제작자의 동의를 받아 번역 문자열을 사용해 Quest 버전으로 제작했습니다. 번역을 제공하고 도움을 주신 제작자분께 감사드립니다.

Quest 버전 제작: **VR 유튜브 크리에이터 제콜**  
유튜브: [youtube.com/@zecole](https://www.youtube.com/@zecole)

## 설치 방법

준비물: Windows 10/11 64비트 PC, 지원 버전의 게임이 설치된 Quest, 데이터 전송이 가능한 USB 케이블.
PC에는 최소 12GiB, Quest에는 최소 5GB의 여유 공간을 확보해 주세요.

1. 릴리스에 첨부된 **설치용 ZIP**을 내려받아 전체 압축을 풉니다. 예: `C:\ITR2Patch`. GitHub의 `Source code` ZIP은 설치본이 아닙니다.
2. Quest의 개발자 모드를 켜고 게임을 완전히 종료합니다.
3. Quest를 PC에 USB로 연결하고, 헤드셋에서 **USB 디버깅을 허용**합니다.
4. 압축을 푼 폴더에서 **설치.bat**을 더블클릭합니다.
5. 완료 안내가 나올 때까지 기다린 후 게임을 실행합니다. 한국어를 따로 선택하지 않아도 됩니다.

Python이나 SideQuest를 별도로 설치할 필요는 없습니다. ADB가 없으면 첫 실행 시 약관 확인 후 자동으로 다운로드하며, 이때 인터넷 연결이 필요합니다.

설치 중에는 USB 케이블을 분리하거나 게임을 실행하지 마세요. 설치 폴더와 그 안의 `userdata` 백업 폴더는 복구를 위해 보관해 주세요. 일부 문구는 영어로 표시될 수 있습니다.

## 원본 복구 방법

1. 게임을 완전히 종료합니다.
2. Quest를 PC에 USB로 연결하고 USB 디버깅을 허용합니다.
3. 패치 설치에 사용했던 폴더에서 **복구.bat**을 더블클릭합니다.
4. 완료 안내 후 게임을 실행합니다.

게임 파일을 원본으로 복구하며, 세이브 진행 상황은 되돌리지 않습니다. 복구에는 지원 버전과 유효한 원본 백업이 필요합니다. 게임이 이미 업데이트된 경우 이전 버전의 복구 도구를 적용할 수 없습니다.

## 게임 업데이트 안내

**게임 버전이 바뀌면 해당 버전용 한글패치가 업데이트되기 전까지 이 패치를 이용할 수 없습니다.**

현재 지원 버전은 **1.2.3 (478362)**입니다. 다른 버전에는 설치가 중단되며, 게임 업데이트 후에는 새 패치를 기다려 주세요.
