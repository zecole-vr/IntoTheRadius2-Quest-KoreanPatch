Into the Radius 2 Quest 한글패치 — 간편 설치 RC2 / 공개 전 검토본

빠른 설치
1. ZIP 전체를 쓰기 가능한 PC 폴더에 압축 해제합니다. 예: C:\ITR2Patch
2. 게임을 완전히 종료하고 Quest 한 대를 USB로 연결합니다.
3. 헤드셋에서 USB 디버깅을 허용합니다. 개발자 모드가 켜져 있어야 합니다.
4. 설치.bat을 더블클릭합니다.
5. 설치 완료 후 게임을 실행합니다. 한국어를 따로 선택하지 않아도 됩니다.

Python이나 SideQuest를 따로 설치할 필요가 없습니다.
기존 ADB가 있으면 자동으로 사용합니다. 없을 때는 처음 한 번 Google 약관을
확인하고 Y를 입력하면 공식 ADB를 자동 다운로드합니다. 이때 인터넷이 필요합니다.
약관 보기 V / 취소 N. 동의를 대신 처리하거나 자동으로 수락하지 않습니다.
다운로드 파일을 검사하고 이 폴더의 .tools에 보관하므로 이후에는 재사용합니다.
ADB는 ZIP에 동봉하지 않습니다. 약관: https://developer.android.com/studio/terms

지원 조건
- Windows 10/11 64비트(x64), 정식 설치된 Quest 단독판 1.2.2 / 473002 전용.
- Quest 3에서 게임 패치의 실제 플레이 확인. Quest 3S는 미검증.
- PC 작업 드라이브 최소 12GiB, Quest 최소 5GB 여유 공간.
- 다른 게임 버전은 적용하지 않습니다. 업데이트 후 재검증이 필요합니다.
- ZIP 안에서 실행하지 마세요. EXE와 data, manifest.json을 함께 보관하세요.
- 한글·공백 경로에서 EXE 및 배치 실행을 점검했습니다. 짧은 로컬 경로를 권장합니다.

진행 중 주의
원본 검사 → PC 원본/세이브 백업 → 패치 생성/검사 → 전송 → 교체 순서입니다.
몇 GB를 검사하고 전송하므로 잠시 기다려 주세요.
작업 중 케이블을 빼거나 게임을 실행하지 마세요.
APK 설치·재서명, 계정 로그인, 세이브 덮어쓰기는 하지 않습니다.
관리자 권한을 요구하지 않습니다.

설치가 끝나면
설정 화면의 회색 글씨와 PDA 설명, 기존 세이브 불러오기를 확인하세요.
PROFILE, 업데이트 안내 등 일부 영어는 남을 수 있습니다.
전체 임무와 모든 UI를 검증한 것은 아닙니다.

원본 복구
게임을 종료하고 USB로 연결한 뒤 복구.bat을 실행합니다.
게임 원본만 복구하며 세이브 진행은 되돌리지 않습니다.
제거한 수정본은 기기에 .questko-retired-... 이름으로 보관합니다.

문제 확인
- 상태확인.bat: 원본/패치 상태와 버전 확인.
- 파일검사.bat: 배포 데이터 손상 검사. 인터넷이나 기기 연결 불필요.
- 연결 오류: USB 디버깅 허용, 데이터 케이블, 다른 기기 연결 여부 확인.
- 게임 실행 중 오류: 게임을 종료하고 다시 실행.
- 다운로드 오류: 인터넷 확인. 공식 다운로드가 사라졌거나 체크섬이 다르면 중단합니다.
- operation.lock 오류: 다른 설치/복구 작업이 끝났는지 확인한 후 해당 작업 폴더의
  operation.lock만 제거하고 다시 실행. 백업은 삭제하지 마세요.
- 오류 시 반복 실행하기보다 창의 오류 메시지를 보관하세요.

백업과 배포
userdata는 개인 세이브 및 원본 백업 폴더입니다. 삭제하지 말고 보관하세요.
개인 백업이나 .tools를 포함해 다시 압축하지 말고 원래 제공된 ZIP을 공유하세요.
원 번역 제작자의 이식·재배포 허락은 확인 예정입니다. 허락 확인 전 공개 배포하지 마세요.
폰트/도구 라이선스: licenses 폴더, THIRD_PARTY_NOTICES.md.
검증 범위: VALIDATION.md. 설치·복구 새 EXE를 통한 실기 교체는 아직 미검증입니다.

고급 사용(선택)
ITR2QuestPatch.exe install --adb "C:\경로\adb.exe"
ITR2QuestPatch.exe install --work-dir "D:\ITR2Backup"
ITR2QuestPatch.exe restore --work-dir "D:\ITR2Backup"
작업 폴더를 지정했다면 복구 때도 같은 폴더를 지정하세요.
