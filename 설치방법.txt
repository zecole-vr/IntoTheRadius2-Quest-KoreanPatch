Into the Radius 2 Quest 한글패치 — 단일 EXE 검토본
패치 v1.2.4-rc.2 / Meta Quest · Standalone / 지원 게임 1.2.4 (480012)

설치
1. ITR2_Quest_v1.2.4-rc.2.exe를 실행합니다. 압축을 풀 필요가 없습니다.
2. Quest의 개발자 모드를 켜고 USB로 연결합니다.
3. 헤드셋에서 USB 디버깅을 허용하고 게임을 완전히 종료합니다.
4. 한글패치 설치 / 업데이트 버튼을 누릅니다.
5. 완료 후 게임을 실행합니다. 한국어 선택은 필요하지 않습니다.

Python 별도 설치는 필요 없습니다. ADB가 없으면 약관 동의 후 자동 다운로드합니다.
Windows 10/11 64비트와 Microsoft Edge WebView2 Runtime이 필요합니다.
WebView2 공식 안내: https://developer.microsoft.com/microsoft-edge/webview2/
PC에 최소 12GiB, Quest에 최소 5GB 여유 공간을 확보해 주세요.

복구
같은 EXE를 실행하고 제거 · 원본 복구 버튼을 누릅니다. 세이브 진행 상황은 유지됩니다.
백업·설치 기록: %LOCALAPPDATA%\ZECOLE\ITR2QuestPatch\userdata
오류 로그: %LOCALAPPDATA%\ZECOLE\ITR2QuestPatch\logs
EXE 파일을 옮기거나 다시 내려받아도 위 폴더의 기록과 백업은 유지됩니다.
설치·복구 안내 창의 백업 폴더 열기로 확인할 수 있습니다.
기존 ZIP 설치본의 userdata 백업은 자동 이전하지 않으므로 따로 보관해 주세요.

게임 업데이트
게임 버전이 바뀌면 해당 버전용 패치가 나올 때까지 이용할 수 없습니다.
이 파일은 공개 전 검토본이며 새 런처의 실기기 설치·제거 및 최종 자막 플레이 검증이 남아 있습니다.
